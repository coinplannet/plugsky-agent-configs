# Directus + Plugsky

Directus has a built-in OpenAI-compatible AI provider.

**Settings → AI → OpenAI-Compatible Provider:**

- Provider Name: `Plugsky`
- Base URL: `https://api.plugsky.com/v1`
- API Key: `sk-live-...`
- Models: `plugsky-pro`

Custom LLM providers may be plan-gated in Directus Cloud; check the plan before configuring.

Docs: https://plugsky.com/docs · Pricing: https://plugsky.com/pricing
