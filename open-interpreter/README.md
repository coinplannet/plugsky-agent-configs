# Open Interpreter + Plugsky

Merge `config.toml` into `~/.openinterpreter/config.toml`, then export the key:

```bash
export PLUGSKY_API_KEY=sk-live-...
```

`wire_api = "chat"` is the safest mode; `responses` also works if your build supports it.

Docs: https://plugsky.com/docs · Pricing: https://plugsky.com/pricing
