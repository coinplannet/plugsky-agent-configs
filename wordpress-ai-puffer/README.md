# WordPress AI Puffer (AI Power) + Plugsky

AI Puffer builds the URL as `base + / + api_version + path`, so keep the version separate.

**AI Puffer → Settings → AI → OpenAI:**

- Base URL: `https://api.plugsky.com`
- API Version: `v1`
- API Key: `sk-live-...`
- Model: `plugsky-pro`

Do not put `/v1` in the base URL; it would become `/v1/v1/...`.
