# Obsidian Copilot + Plugsky

**Settings → Copilot → BYOK → Add a provider → Add a custom provider:**

- Base URL: `https://api.plugsky.com/v1`
- API key: `sk-live-...`
- Model ID: `plugsky-lite` or `plugsky-pro`

Click **Test** then **Save**. Keys are stored in the OS keychain, not in the vault.

Docs: https://plugsky.com/docs · Pricing: https://plugsky.com/pricing
