# Zed + Plugsky

Merge `settings.json` into your Zed settings. Zed does not store the key in `settings.json`; add it through the provider UI/keychain or export `PLUGSKY_API_KEY` (Zed derives the env var from the provider id).

Use `plugsky-pro` for general work and `plugsky-coder` for coding. The API URL includes `/v1`.

Docs: https://plugsky.com/docs · Pricing: https://plugsky.com/pricing
