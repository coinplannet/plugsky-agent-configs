# Mattermost Agents + Plugsky

**Agents → Settings → AI services → Add an AI Service:**

- Service type: `OpenAI Compatible`
- API URL: `https://api.plugsky.com/v1`
- API Key: `sk-live-...`
- Default model: `plugsky-pro`
- Use Responses API: **off** (safe default)

The free Mattermost Agents licence allows one LLM service and one agent, which is enough for a first deployment.

Docs: https://plugsky.com/docs · Pricing: https://plugsky.com/pricing
