# Chatbox + Plugsky

**Settings → Providers → Add Custom Provider:**

- Provider name: `Plugsky`
- API Host: `https://api.plugsky.com/v1`
- API Path: `/chat/completions`
- API Key: `sk-live-...`
- Model: `plugsky-lite` or `plugsky-pro`

Chatbox uses a host + path pair. Keep `/v1` in the host and `/chat/completions` in the path.

Docs: https://plugsky.com/docs · Pricing: https://plugsky.com/pricing
