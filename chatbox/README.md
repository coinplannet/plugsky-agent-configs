# Chatbox + Plugsky

**Settings → Providers → Add Custom Provider:**

- Provider name: `Plugsky`
- API Host: `https://api.plugsky.com`
- API Path: `/v1/chat/completions`
- API Key: `sk-live-...`
- Model: `plugsky-lite` or `plugsky-pro`

Chatbox uses a host + path pair, so do not put `/v1/chat/completions` into the host field.

Docs: https://plugsky.com/docs · Pricing: https://plugsky.com/pricing
