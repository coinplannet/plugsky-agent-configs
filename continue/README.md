# Continue + Plugsky

Merge `config.yaml` into `~/.continue/config.yaml` (or replace it if you do not have one).

- `plugsky-coder` fills the chat, edit and apply roles.
- `plugsky-embed` fills the embed role for codebase indexing.
- The key is read from the `PLUGSKY_API_KEY` secret; never commit the real key.

Free plan: 100 requests/day, 50K tokens/day. For sustained coding-agent use, Hobby at $8/month gives 1,000 requests/day, 2M tokens/day and 4 concurrent requests.

Docs: https://plugsky.com/docs · Pricing: https://plugsky.com/pricing
