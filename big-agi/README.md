# Big-AGI + Plugsky

**Models → OpenAI → API Host:** `https://api.plugsky.com/v1`

Paste the key and add `plugsky-lite` / `plugsky-pro` as model IDs. Big-AGI calls this the OpenAI vendor host, so the value is the full base URL including `/v1`.
