# Cline

Cline has a built-in **OpenAI Compatible** provider.

1. Open Cline → Settings → API Configuration.
2. Provider: **OpenAI Compatible**.
3. Base URL: `https://api.plugsky.com/v1`
4. API Key: your Plugsky key (`sk-live-...`). Get one at https://plugsky.com/.
5. Model ID: `plugsky-lite` (image input) or `plugsky-micro` (text only).

For agent loops, the free tier's 100 requests/day and 2K output cap are tight. Hobby at $8/month raises the limits to 1,000 requests/day, 2M tokens/day and 8K output.
